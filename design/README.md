# Handoff: Лендинг «Лучшая CRM» (личная CRM)

## Overview
Визуальный стиль — **вариант 2**: оранжевый акцент `#EE8208`, шрифт Rubik, тёплый фон, pill-кнопки.

Статичный одностраничный лендинг личной CRM — записной книжки для людей, которых пользователь знает лично. **Единственное целевое действие — переход в приложение.** Все кнопки ведут на один URL приложения.

Стек: **Astro + Tailwind CSS 4**, статическая сборка (`output: 'static'`), без клиентского JS-фреймворка.

## About the Design Files
Файлы в этой папке — **дизайн-референсы в HTML**, а не продакшн-код. Их нужно воссоздать в Astro + Tailwind 4 по принятым там паттернам: компоненты `.astro`, утилитарные классы Tailwind, токены через `@theme`.

- `Landing Mobile.dc.html` — **мобильная версия (x)**, ширина 390 px. Эталон для брейкпоинтов `< md`.
- `Landing Desktop.dc.html` — **десктопная версия (y)**, контейнер шириной до 1200 px. Эталон для брейкпоинтов `≥ lg`.
- `landing-copy.md` — исходный текст лендинга. Тексты в макетах взяты из него, кроме отличий, перечисленных ниже.
- `support.js` — служебный рантайм для открытия макетов в браузере. В проект **не переносить**.

Макеты открываются в браузере напрямую. Все стили заданы inline: значения можно смотреть в коде.

## Fidelity
**High-fidelity.** Цвета, типографика, отступы, радиусы и тексты финальные. Воспроизводить пиксель в пиксель.

```
src/
  layouts/Base.astro          // <html>, шрифт, мета, body bg
  pages/index.astro           // собирает секции по порядку
  components/

    HowItWorks.astro  Numbers.astro  Audience.astro  Reviews.astro

    ui/CtaButton.astro        // variant: primary | soft | inverse
    ui/Card.astro             // белая карточка с радиусом
```

- Повторяющиеся элементы (ситуации, фичи, отзывы, тарифы, FAQ) рендерить из `content.ts` через `.map()`.
- Порядок секций: 01 → 13, как ниже.

### Radius
- Секции-карточки: **20 px** mobile / **24 px** desktop
- Внутренние карточки (фичи, цифры, отзывы, тарифы): **20 px**
- Вложенные плашки: **14 px** mobile / **16 px** desktop
- Кнопки: **pill** (`border-radius: 999px`) — все CTA, включая кнопки тарифов и кнопку в шапке. Основные оранжевые кнопки имеют тень `0 8px 20px rgba(238,130,8,.3)`.
- Чипы/теги: **8 px**, мелкие бейджи: **6 px**
- Номера фич: квадрат 40/44 px, радиус 12 px. Номера шагов: круг 32/40 px.

### Spacing
- Mobile: внешний отступ секций **12 px** (секции — карточки с отступом от краёв экрана), внутренний padding **24 × 20 px**, gap между элементами 8 / 12 / 16 px.
- Desktop: контейнер `max-width: 1200px`, padding по бокам 24 px, gap между секциями **16 px**, внутренний padding секций **48 × 56 px** (Hero: 56 px), gap сеток 12 px.
- Заголовки секций **без** белой подложки (блоки 03, 06, 08, 09): отступ `12/32 px 8px 4/8px` — чуть выше и левее, чтобы выровнять по краю карточек.

### Shadows / borders
- Карточки плоские, без теней. Тень есть только у основных CTA (см. Radius).
- Выделенный тариф «Плюс»: `box-shadow: inset 0 0 0 2px #EE8208`.

## Layout pattern
Визуальная система: **белые карточки с крупным радиусом на тёплом кремовом фоне `#FFF6EC`**, плотная компоновка, один оранжевый акцент и pill-кнопки. Есть два типа секций:
1. **Секция-карточка**: весь блок лежит в одной белой карточке (02, 04, 05, 07, 10, 11).
2. **Секция-сетка**: заголовок лежит на кремовом фоне, под ним сетка отдельных белых карточек (03, 06, 08, 09).

## Interactions & Behavior
- **Все CTA** (шапка, Hero, «Создать свою книжку», тарифы, финальный CTA) — это `<a href={APP_URL}>`. Тарифы можно передавать параметром: `?plan=free|plus|lifetime`.
- Hover у основной кнопки: фон `#DB7500`. У ссылок и soft-кнопок: `opacity: .85`. Добавить видимый `focus-visible` ring (`outline: 2px solid #EE8208; outline-offset: 2px`).
- Шапка sticky. Якоря скроллят плавно.
- FAQ работает на `<details>`, без JS.
- Анимаций нет.

## Responsive
- Mobile-first. Макет x (390 px) — база, макет y — `lg` (≥ 1024).
- Desktop-сетки в макете сделаны через `repeat(auto-fit, minmax(N, 1fr))`. В Tailwind их можно повторить или задать явно: `grid-cols-1 md:grid-cols-2 lg:grid-cols-3/4/5`.
- Mobile: секции в виде карточек с отступом 12 px от краёв. Контент страницы ограничен по ширине (на планшете можно `max-w-[640px] mx-auto` до перехода на desktop).
- Навигация в шапке видна только на desktop (`hidden lg:flex`).
